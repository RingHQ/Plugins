# RGB

The ring runs through the rainbow while it is open.

The lit segment and the preview border cycle through all colors, fading
into a neighbouring one, and the rest of the ring glows along more dimly.
One trip round the color wheel takes three seconds.

## Actions

None. Enable the plugin and open the ring.

## Good to know

- It replaces your accent, gradient and ring colors while it is enabled.
  Disable it and they are back.
- A preview border with its own color (not "accent") keeps that color.
- The colors only move while the ring is open; nothing runs in between.
- Needs a Ring whose plugin interface is at version 2 or later.
