# Swap

Let the active window change places with another one.

Each of the two takes the frame the other had.

## Actions

| Action | What it does |
|---|---|
| `swap.largest` | Change places with the largest other window. |
| `swap.next` | Change places with the next window, going left to right. |
| `swap.previous` | The same, in the other direction. |

Only windows of the current desktop on the monitor in use take part. With no
other window there, nothing happens.

## Good to know

Undo brings back the active window only. Swap again to put both back.
